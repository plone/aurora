# @plone/aurora-dev

The Plone Aurora app for developing Plone Aurora itself, in this repository.
It is private and never published.

Projects don't use this app: they install the [`@plone/aurora`](../../packages/aurora) framework.
See the [Plone Aurora documentation](https://plone-aurora.readthedocs.io/) to create a project, and [Developing core](https://plone-aurora.readthedocs.io/contributing/developing-core.html) to work on Plone Aurora.

From the root of the repository:

```shell
make install
make start
```
