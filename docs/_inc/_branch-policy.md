Plone Aurora is in its alpha phase, and has a single branch in git, `main`.

`main`
:   This is the branch upon which all development occurs.
    Releases of Plone Aurora and of its packages (`@plone/registry`, `@plone/client`, `@plone/plate`, and so on) are cut from it.
    There are no maintenance branches yet, so fixes are released only in the next release.

    When opening a pull request, you must open it against `main`.
    See {ref}`contributing-branch-policy-for-translations-label` for translations.
